# Superstore Sales Analysis

## Overview
Exploratory Data Analysis of Superstore sales data to uncover trends in sales, profit, and customer behavior.

## Key Insights
- Technology category generated highest revenue (~865k USD)
- 70-80% discounts lead to significant losses
- Consumer segment is the most profitable
- Sales peak in Q4 (Oct-Dec)

## Tools Used
- Python, Pandas, NumPy
- Matplotlib & Seaborn for visualization
- Jupyter Notebook

## Project Structure
- `Superstore_Sales_Analysis.ipynb` - Main analysis notebook
- `Superstore Sales.csv` - Dataset
